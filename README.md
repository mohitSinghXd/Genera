
# Quicky
Quicky is an AI-powered notes generation platform where users can generate smart exam notes based on topics and download them as PDF. The platform also includes authentication and subscription-based premium access.

# Tech Stack
- Frontend: React, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB , SQL
- Payments: Stripe

Features
- JWT Authentication
- Google Login
- AI Notes Generation
- PDF Download
- Stripe Subscription System


# Setup Instructions
- Clone the repository
- Install dependencies in frontend and backend
- Add required environment variables
- Run backend and frontend servers
